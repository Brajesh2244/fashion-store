## 🌟 Key Features
- **Interactive Product Catalog:** Browse apparel, filter by categories, and view detailed product specs.
- **Cart & Wishlist Management:** Add, remove, update item quantities with instant subtotal calculations.
- **Checkout & Payment Flow:** Multi-step order checkout, payment method selection, and order confirmation.
- **User Authentication:** Login, registration, and user profile management.
- **Database Architecture:** Normalized MySQL relational schema for products, categories, orders, and users.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+), Responsive Grid/Flexbox Layouts
- **Backend:** Java, Jakarta Servlets, JSP, JDBC
- **Database:** MySQL (see `database_setup.sql`)
- **Deployment:** Vercel (Frontend Demo), Docker-ready (see `Dockerfile.backend`)
